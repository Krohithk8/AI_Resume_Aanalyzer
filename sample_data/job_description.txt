Mid-Level Python Backend Engineer

About the role
We are seeking a Python Backend Engineer to build reliable services for our B2B analytics platform. You will design and maintain RESTful APIs, improve database performance, and work with product and data teams to ship customer-facing capabilities.

What you will do
- Build and operate scalable Python services using FastAPI or Django.
- Design REST APIs and asynchronous background workflows.
- Write PostgreSQL queries, data migrations, and performance improvements.
- Deploy containerized services to AWS using CI/CD pipelines.
- Add automated tests, monitor production systems, and participate in on-call support.
- Collaborate in an Agile team and contribute thoughtful code reviews.

What we are looking for
- 3+ years of professional backend development experience.
- Strong Python, Django or FastAPI, SQL, and PostgreSQL skills.
- Experience with Docker, AWS, Git, pytest, and REST API design.
- Familiarity with Redis, Celery, Kubernetes, Terraform, observability tools, and message queues is a plus.
- Clear written communication and an evidence-driven approach to engineering.
